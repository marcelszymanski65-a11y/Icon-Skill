# Icon library reference guide

Use this guide to choose a suitable library. Always check the library's current documentation for exact names, package installation, licensing, and framework syntax.

| Library | Good default use | Official reference |
|---|---|---|
| Lucide | Clean, consistent outline icons; general-purpose interfaces | https://lucide.dev/ |
| Tabler Icons | Broad outline icon set; product interfaces | https://tabler.io/icons |
| Heroicons | Tailwind-oriented interfaces and familiar UI patterns | https://heroicons.com/ |
| Phosphor | Multiple weights and expressive visual options | https://phosphoricons.com/ |
| Fluent UI System Icons | Microsoft ecosystem and Fluent-style products | https://github.com/microsoft/fluentui-system-icons |
| Solar Icons | Distinctive modern icon family with multiple styles | https://solar-icons.dev/ |
| Material Symbols | Material Design systems and Google-style interfaces | https://fonts.google.com/icons |

## Selection order

1. Match the project's existing icon dependency and design system.
2. If none exists, choose Lucide unless another library is a clearly better fit.
3. Keep a single visual language across the interface.
4. Verify every icon name and import against the selected library's current documentation.

# Icon usage patterns

These patterns are guidance, not mandatory decoration.

## Good opportunities

- A magnifying-glass icon for search
- A gear icon for settings
- A bell icon for notifications
- A user/profile icon for account navigation
- A calendar icon beside date-related metadata
- A map-pin icon beside a location
- A download icon for a download action
- A check or alert icon for meaningful status feedback

## Avoid

- Adding an icon to every paragraph or bullet
- Using unrelated icons purely to fill empty space
- Mixing filled, outlined, and multicolor icon styles without a design reason
- Using an icon without a text label when its meaning is not obvious
- Replacing meaningful text with an ambiguous symbol
- Using emoji as a stand-in for a real UI icon

## Accessibility

- Provide accessible labels for icon-only buttons.
- Keep visible text labels where an icon may be ambiguous.
- Do not rely on color alone to communicate status.
- Ensure adequate contrast and target size.
